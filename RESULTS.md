## Stage 3 local billing query probe

The [before plan](tools/bench/results/stage3-billing-query-before.json) was saved before migration 007. The raw JSON includes the full plans, row count, scope, and sample times. No Stage 2 benchmark file was edited.

## Stage 4 local fictional explanation evaluation and injected operations

The [frozen 32-case input](tools/fault-fixtures/explanation-cases-v1.json) has SHA-256 `c14b04b404c2b7cf1d98d02be8fe512012edddd7a4b1b53ec4b5f7b3324c8554`; it contains **fictional billing examples**, not HSB observations. The [final raw case-level evaluation](tools/bench/results/stage4-explanations-v4.json) records each expected label, deterministic output, raw Groq response, validation outcome, token usage, and latency. Frozen cases preceded prompt tuning; [v2](tools/bench/results/stage4-explanations-v2-before-tuning.json) and [v3](tools/bench/results/stage4-explanations-v3.json) are preserved. The deterministic template agreed with **32/32** frozen primary-reason labels. On this account, Groq `openai/gpt-oss-20b` strict output achieved **32/32 raw primary-reason agreement, 32/32 accepted outputs, 0 fallbacks, and 0 rejected outputs** across 32 actual HTTP calls. Case latency had 581.679 ms median, 757.02 ms p95, and 211.284–1,224.881 ms range. The final evaluation used 14,420 prompt tokens and 2,825 completion tokens. It did not repeat statement requests, so evaluation cache savings are 0 calls and 0 tokens; no monetary savings is claimed.

The [local fault drill](docs/data/stage4-fault-drill.json) saved nine bounded request-ID log entries without secrets or resident usage values. An injected database outage returned `/healthz` 200 and `/readyz` 503; an HSB historical-event replay classified one already imported row as duplicate with zero accepted on replay; an edited fictional preview returned 409; injected Groq 429 and timeout each returned deterministic 200 fallbacks. A separate **injected transport** cache probe made one mock model call followed by one cache response, avoiding one further mock call. This does **not** measure actual Groq calls or tokens avoided. These are local tests, not hosted traffic. No monetary saving or certified HSB bill is inferred.

The [hosted Supabase/local API smoke](docs/data/stage4-hosted-local-api-smoke.json) ran 23 checks using three actual fictional Supabase Auth users and the local Express API connected to the hosted private database. Two fictional billing revisions remained readable. Two actual Groq explanation requests were followed by cache responses, avoiding **two repeat HTTP calls** (the response counter records 1 each); no token-saving figure was derived. The unauthenticated and authenticated resident Data API probes both returned HTTP 406 for `app.societies`. This is a local API connected to hosted dependencies, **not a deployed Render observation**. The [hosted HSB import](docs/data/stage4-hosted-hsb-import.json) accepted 1,000 checksum-verified historical events; its [replay](docs/data/stage4-hosted-hsb-replay.json) accepted 0 and classified 1,000 duplicates. The full archive was not sent to Supabase or Render.
